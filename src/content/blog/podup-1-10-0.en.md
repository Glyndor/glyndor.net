podup 1.10.0 is out. One thing worth calling out:

- Service mode now supports quadlet autostart — podup's rootless-Podman equivalent of a systemd service for a compose stack. Your stack can come back up on boot or login without a root daemon.
- New docs: a rootless-autostart guide covering both modes, so you can pick the one that fits your setup.

Full changelog: [v1.9.3...v1.10.0](https://github.com/Glyndor/podup/compare/v1.9.3...v1.10.0).

Install or upgrade: see the [podup project page](/projects/podup) for install methods.
