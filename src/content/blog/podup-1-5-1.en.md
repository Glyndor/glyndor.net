podup 1.5.1 is out. One fix worth calling out:

- `cp` now supports rename-on-copy when copying into a container — the destination filename no longer has to match the source. It also accepts single-character service names, which were previously rejected.

Full changelog: [v1.5.0...v1.5.1](https://github.com/Glyndor/podup/compare/v1.5.0...v1.5.1).

Install or upgrade: see the [podup project page](/projects/podup) for install methods.
